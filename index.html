Help?

A personal token unlocks 5,000 requests/hr and private repos. It is optional for public repos.

  1. 1. On GitHub, open Settings > Developer settings > Personal access tokens.
  2. 2. Generate a token with read access to repository contents.
  3. 3. Paste the token into the input field above.
