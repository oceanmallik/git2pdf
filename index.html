Hitting GitHub's rate limit?

GitHub limits anonymous requests to 60/hr. If you hit the rate limit or want to export private repos, log in or provide a token:

Logged in with GitHub
or
Help?

A personal token unlocks 5,000 requests/hr and private repos. It is completely optional for public repos.

  1. 1. On GitHub, open Settings > Developer settings > Personal access tokens.
  2. 2. Generate a fine-grained or classic token with read-only Repository Contents permission.
  3. 3. Paste the token above.

We do not store your token. It is stored purely locally in your browser. Don't believe me? See the code on GitHub.
