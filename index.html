How to get a token

A token lets you open private repos and avoids rate limits. It is optional for public repos.

  1. 1. On GitHub, open Settings > Developer settings > Personal access tokens > Fine-grained tokens.
  2. 2. Click Generate new token and give it any name.
  3. 3. Under Repository access, pick the repo(s) you want.
  4. 4. Under Permissions > Repository permissions, set Contents to Read-only.
  5. 5. Click Generate and copy the token. Paste it here.

The token stays in your browser and is only sent to GitHub.
